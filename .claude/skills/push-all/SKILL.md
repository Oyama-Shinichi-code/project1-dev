# push-all

現在の作業ディレクトリの変更を、検証用リポジトリ (`dev`) と本番リポジトリ (`origin`) の両方に反映する。

このコマンドの実行自体が、本番への反映についてのユーザーの明示的な指示とみなす（CLAUDE.mdの「本番(origin)へはユーザーの明示的な指示があった場合のみ反映する」というルールを満たす）。

## 手順
1. `git status` で変更内容を確認する。コミットされていない変更がなければ、その旨をユーザーに伝えて終了する。
2. `git status` の内容を確認し、`.env` 等の秘密情報を含むファイルが含まれていないか確認する。含まれていた場合はユーザーに警告し、除外の指示を待つ。
3. `git add -A` でステージし、変更内容から簡潔なコミットメッセージ（「なぜ」を中心に）を生成して `git commit` する。コミットメッセージの最後に `Co-Authored-By: Claude Sonnet 5 <noreply@anthropic.com>` を付ける。
4. `git push dev main` を実行する。
5. `git push origin main` を実行する。
6. 両方の結果（コミットハッシュ、各push先URL）を簡潔に報告する。

## 注意
- 本番 (`origin`) へのpushはこのコマンドでのみ行う。通常の作業では `/push-dev` を使う。
- devとoriginでpush結果が食い違った場合（例: 片方だけ失敗）は、その旨を明確にユーザーに報告する。
