# 手動テストチェックリスト（desktop_pet）

実機操作・見た目確認が必要な項目のまとめ。`pytest`（`tests/test_*.py`）は数値計算・判定ロジックのみ検証でき、
GUI操作の見た目・タイミング・アニメーションはここで確認する。

機能を追加・変更したら、該当セクションに項目を追記していくこと。チェックは都度リセットしてよい
（「このバージョンで最後に確認した日」を各項目末尾に書き足す運用でもよい）。

起動: `.venv/Scripts/python.exe -m desktop_pet.main`

---

## 1. 基本表示・ウィンドウ操作

- [ ] 起動直後、ペット画像・右下トグルボタン列・ナレーション欄が正しい位置に表示される
- [ ] ウィンドウをドラッグで移動できる（なでるモードOFF時）
- [ ] 四隅のリサイズグリップでアスペクト比を保ったまま拡大・縮小できる（最小/最大スケールで止まる）
- [ ] 👁ボタンでリサイズグリップのL字デザイン表示/非表示が切り替わる（top_rightは常にデザインなし）
- [ ] 📌ボタンで最前面⇔最背面が切り替わる。最背面中は他ウィンドウをクリックしても背面を維持する
- [ ] 右下トグルボタンをドラッグ&ドロップで並び替えられる。並び順は再起動後も保持される

## 2. ステータスパネル（📊）

- [ ] 開閉がアニメーション付きでスムーズに行える
- [ ] 満腹度・機嫌・体力・なでAPの4本のゲージが正しい値で表示され、低いほど赤、高いほど緑に色が変わる
- [ ] 「なつき度 あと◯」「連続ケア◯回/◯日」が表示され、操作のたびに更新される
- [ ] ペット画像左下の「Lv.◯」表示が常時見える（ステータスパネルの開閉に関係なく）

## 3. 餌やり・なでる（基本アクション）

- [ ] 🍖餌やりで満腹度が回復し、食べかすモーション→ハート演出が出る
- [ ] 満腹（100）の状態で🍖を押すと「あげすぎ」演出（💢＋シェイク）になり、機嫌・なつき度が下がる
- [ ] 🤚（button_bar内）でなでるモードをON/OFFできる。ONの間だけキャラ上をドラッグでこすれる
- [ ] こすっている間、手のアイコン🤚と光の粒子エフェクトがカーソルに追従する
- [ ] 一定距離こすると機嫌回復のハート演出が出る（なでAPが十分ある時）
- [ ] なでAPを使い切った状態でさらになでると、ハートではなく💢演出になり、なつき度が下がる
- [ ] なでAP・機嫌は時間経過で自然回復/減少する（⏰で時間を進めて確認）

## 4. 時間操作（⏰）

- [ ] +10分/+1時間/+1日/-1時間/-1日の各ボタンでステータスが正しい方向に変化する
- [ ] 時間を戻した場合、ステータス変化は巻き戻らない（オフセットのみ戻る）

## 5. 会話機能（💬）

- [ ] 名前未設定の間は入力欄・送信ボタンが無効化され、プレースホルダーに案内が出る
- [ ] 名前を入力すると即座に会話可能になる（設定ボタン不要）
- [ ] 通常の発言を送信すると、ナレーション文・評価レベル・mood変化量のふわっと表示が出る
- [ ] 不適切な単語を送信すると、AIのナレーションではなく赤字の定型注意文が表示され、mood変化は起きない
- [ ] 通信エラー時・APIキー未設定時にエラーメッセージが表示される
- [ ] ✕ボタンで会話パネルを閉じられる。閉じるボタンの位置が他要素と重ならない

## 6. ナレーション欄（画面下部常時表示）

- [ ] 操作（餌やり・なでる・あげすぎ・なですぎ等）のたびに、原因が分かる定型文が表示される
- [ ] 1回の操作で複数件変化した場合、順番に（数秒ずつ）切り替わって表示される
- [ ] 操作直後にすぐ反映される（表示が極端に遅れない）
- [ ] 長文は全文表示後に一度だけ左へ流れ、その後静止して消える（延々ループしない）
- [ ] 📜ボタンでログ一覧が開き、直近の操作履歴が日時付き・新しい順で表示される
- [ ] ログ一覧のタイトルは「ログ」とシンプルな表記になっている
- [ ] 5分ほど放置すると、AIによるアイドル実況（ユーモラスな一文）が表示される（要APIキー）
- [ ] ☰メニューを開いてもナレーション欄・メニュー双方の表示位置が崩れない

## 7. レベル・なつき度システム

- [ ] 適切なタイミングでの餌やり・なでるでなつき度が上がり、「なぜ上がったか」が分かる文言が出る
- [ ] 不適切な世話（あげすぎ・なですぎ）でなつき度が下がり、理由付きの文言が出る
- [ ] なつき度が一定量たまるとレベルが上がり、「レベルが◯に上がった！」が優先的に表示される
- [ ] 不適切な世話を連続（6回程度）行うとレベルが下がり、「レベルが◯に下がった」が優先的に表示される
- [ ] レベルが低いほど機嫌の自然減衰が速く、なでた時の回復量も少ない（体感レベルでよい）

## 8. 構ってほしいイベント（❗）

- [ ] 放置していると低確率で❗アイコンが画面左上あたりに表示される
- [ ] 表示中になでる/餌やりをすると、通常より多いなつき度ボーナスが入り、専用の文言が出る
- [ ] 無視して時間（10分相当）が経過すると、ペナルティなく自然に消える

## 9. 睡眠機能

- [ ] 😴デバッグボタンで即座に入眠する（立ち絵が睡眠用に変わる、またはnormalの静止画になる）
- [ ] 睡眠中はアニメーションが止まり、キャラが動かない
- [ ] 睡眠中はナレーション欄に「睡眠中のようだ。静かにしてあげよう」が固定表示され続ける（他の文言で上書きされない）
- [ ] 睡眠中に⏰で時間を進めると、体力が回復し、満腹度の減少が緩やかになり、機嫌は変化しない
- [ ] 睡眠中に🍖または🤚を使うと、強制的に起こされ、機嫌・なつき度が大きく下がる（「起こされた」文言が出る）
- [ ] 睡眠中に満腹度を0まで下げると、自動的に起床する
- [ ] 持続時間（デフォルト1時間相当）が経過すると、ペナルティなしで自然に起床する
- [ ] 満腹度が満タン（100）の状態で入眠すると、なつき度・機嫌の少量ボーナス、睡眠時間短縮、体力回復速度アップの演出・効果が入る
- [ ] 🌙ボタンはレベル10未満では表示されない。レベル10以上で表示され、時刻設定ダイアログが開く
- [ ] 設定した時刻になると、満腹度が0でなければ自動的に入眠する
- [ ] レベルが10未満に下がると🌙ボタンが再び非表示になる
- [ ] アプリを長時間（数時間〜1日程度）終了した状態にしてから再起動すると、非起動中の経過に応じて正しく睡眠/覚醒状態が反映される（起動直後に寝ていることもある）

## 10. 永続化・セーブデータ

- [ ] アプリを終了して再起動すると、全ステータス（満腹度・機嫌・体力・なつき度・なでAP・レベル・睡眠設定・ナレーションログ・会話履歴・トグルボタン順序・ウィンドウ位置）が保持されている
- [ ] 既存の古いセーブデータ（睡眠機能実装前のもの）を読み込んでもエラーにならず、デフォルト値で補完される

- [ ] exeでもセーブデータの読み書きが正しいパスに対して行われる
